# Word list

The high-traffic entries, condensed from
https://developers.google.com/style/word-list. When a term is not here,
check the full list before improvising. One term per concept: after you
pick a word for something, keep using it.

| Term | Guidance |
| --- | --- |
| above, below | Don't use for a position in the document. Write "the preceding section", "the following table", or link to it. |
| allows you to | Write "lets you". |
| and/or | Rework: "A, B, or both". |
| app, application | "App" is fine everywhere in this repo. |
| as | Don't use to mean "because". |
| backend, frontend | One word, no hyphen. |
| checkbox | One word. You select a checkbox; you don't "check" it. |
| click, tap, select | "Click" with a mouse, "tap" on a touchscreen, "select" when the input method is unknown. |
| codebase | One word. |
| command line, command-line | Noun "command line"; modifier "command-line tool". |
| data | Singular: "the data is". |
| dialog | Not "dialog box". |
| e.g. | Write "for example". |
| easy, easily | Delete, or explain what makes it so. |
| email | No hyphen. |
| enable, disable | For a person acting on a setting, prefer "turn on" and "turn off". "Enable" is fine for what a flag or API does. |
| etc. | Write "and so on", or rework the sentence. |
| filename | One word. |
| i.e. | Write "that is". |
| in order to | Write "to". |
| in the event that | Write "if". |
| internet, web, website | Lowercase. "Website" is one word. |
| just, simply | Delete. |
| kill | Fine as the technical term (`kill`, killed process). Otherwise "stop" or "end". |
| leverage | Write "use". |
| login, log in | Noun or modifier "login"; verb "log in". This repo standardizes on "sign in" and "sign-in" instead. |
| may | Permission only. Use "might" for possibility and "can" for ability. |
| once | Don't use to mean "after": "After the build finishes", not "Once the build finishes". |
| please | Delete from instructions. |
| prior to | Write "before". |
| sanity check | Write "quick check" or "validation". |
| setup, set up | Noun or modifier "setup"; verb "set up". |
| should | Avoid. Say required, recommended (and why), or optional. |
| sign in, sign-in | Verb "sign in"; noun or modifier "sign-in". |
| since | Time only. Use "because" for cause. |
| terminate | Usually "stop" or "end". |
| utilize | Write "use". |
| via | Prefer "through" or "by using". |
| vs. | Write "versus". |
| whitelist, blacklist | Write "allowlist" and "blocklist". |
| Wi-Fi | Capital W, capital F, hyphen. |
| will | Use the present tense instead. |
| wish, desire | Write "want". |
