# Contributing

The public copy of this repository is read-only. A script rebuilds it each week
from a private working repository, so pull requests and issues opened against
the copy are not merged or answered.

- To report a security problem, follow [SECURITY.md](SECURITY.md).
- To use the app, open [snippets.ink](https://www.snippets.ink).
